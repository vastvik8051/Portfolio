Library Management System

Developed a console-based Library Management System in C++ to manage book records, borrowing operations, and search functionality through a modular and scalable program structure.

  • Implemented features for adding, borrowing, returning, and viewing books.
  • Developed search functionality by title and author.
  • Utilized C++ classes, vectors, and constructors for structured program design.
  • Applied modular programming principles to improve scalability and maintainability.
  • Designed a menu-driven interface to simulate real library management operations.
