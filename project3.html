Gesture Motion Control Glove

Developed a gesture-controlled smart device using Arduino, gyro sensors, and flex sensors to recognize hand movements and perform real-time actions through embedded hardware integration.

  • Integrated gyro and flex sensors for gesture detection and motion tracking.
  • Programmed the system using Arduino for real-time input processing.
  • Implemented wireless/device control based on hand gestures.
  • Added speaker/audio output functionality for interactive feedback.
  • Designed and tested hardware connections, sensor calibration, and signal processing.
