Student Database Web App

Developed a full-stack student database web application using the MERN stack with secure user authentication, persistent login functionality, API integration, MongoDB database connectivity, and backend API testing using Postman.

  • Built frontend components using React for dynamic user interaction.
  • Implemented user authentication and persistent login functionality.
  • Integrated REST APIs for real-time data handling and communication.
  • Connected and managed MongoDB database operations.
  • Tested and validated backend APIs using Postman.
  • Deployed the application on Netlify for online accessibility.
