Netflix Clone

Developed a responsive Netflix-inspired streaming web application using the TMDb API for real-time movie and show updates with interactive media playback features.

  • Built a fully responsive UI optimized for desktop and mobile devices.
  • Integrated live API data for dynamic categories, movies, and shows.
  • Implemented audio and video playback functionality.
  • Created reusable frontend components and Netflix-style content sections.
  • Handled asynchronous API fetching and dynamic rendering.
