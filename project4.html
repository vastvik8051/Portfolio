Password Encryption

  • Implemented custom password encryption logic using character mapping and string manipulation.
  • Applied OOP concepts, arrays, and data processing techniques in C++.
  • Built both console-based and Qt GUI versions of the application.
  • Designed an interactive GUI with secure password input and dynamic output display.
  • Added custom styling and basic animations to improve user experience.
