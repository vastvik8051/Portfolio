Bi-Directional Counter

Bi-directional Counter (Arduino UNO) : Designed and built a bi-directional visitor counter using Arduino Uno to detect and count the number of people entering and exiting a room. The system utilized two IR sensors placed at the doorway to determine the direction of movement. It can be used to fully automate a home interior by controlling lights, fans, and air conditioning through motion detection.

  • Integrated dual IR sensors to detect entry and exit direction.
  • Programmed the system using Arduino Uno for real-time visitor counting.
  • Implemented directional movement detection using sensor sequencing logic.
  • Designed the system for smart automation of lights, fans, and air conditioning.
  • Applied embedded programming concepts for motion-based control and monitoring.
  • Tested sensor accuracy, signal processing, and hardware connectivity.
  • Components Used: Arduino Uno, Dual IR Sensors, Jumper Wires, Breadboard, LCD Display (optional), and Power Supply.
