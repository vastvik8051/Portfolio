ATM Simulator

Developed a console-based ATM simulator in C++ that replicates core banking operations including secure login, balance management, deposits, withdrawals, and transaction tracking through a modular program structure.

  • Implemented secure login and user authentication functionality.
  • Developed balance inquiry, deposit, and withdrawal features.
  • Added transaction history tracking for banking operations.
  • Utilized C++ classes, functions, and control structures for modular design.
  • Applied user input validation and error handling techniques.
  • Designed a menu-driven console interface for smooth user interaction.
