Automated Car Parking System

Developed an automated car parking system using Arduino Uno, IR sensors, and SG90 servo motors to detect vehicle movement and automate gate control with efficient embedded programming techniques.

  • Integrated dual IR sensors for vehicle detection and entry/exit monitoring.
  • Controlled SG90 servo motors for automated parking gate operation.
  • Programmed the system using Embedded C/C++ on Arduino Uno.
  • Implemented interrupt-driven logic for accurate real-time detection.
  • Added non-blocking servo control and safety timeout mechanisms.
  • Optimized power delivery and hardware performance for stable operation.
  • Components Used: Arduino Uno, Dual IR Sensors, SG90 Servo Motors, Jumper Wires, Breadboard, and Power Supply.
